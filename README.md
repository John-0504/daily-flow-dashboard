# 오늘의 흐름 ✨

**오늘 할 일, 날씨, 집중 타이머, 계산기를 한 화면에서 사용하는 생산성 앱**입니다. 설치하거나 회원가입할 필요 없이 웹페이지를 열면 바로 사용할 수 있습니다.

## 바로 사용하기

👉 **[오늘의 흐름 앱 열기](https://john-0504.github.io/daily-flow-dashboard/)**

휴대폰과 컴퓨터의 브라우저에서 사용할 수 있습니다. 페이지가 열리지 않으면 잠시 후 새로고침해 주세요.

## 무엇을 할 수 있나요?

| 기능 | 사용 방법 |
| --- | --- |
| ☁️ **날씨 확인** | 앱을 열면 서울 날씨가 표시됩니다. 다른 지역을 보려면 도시 이름(예: `부산`)을 입력하고 **검색**을 누르세요. 기온, 체감 온도, 습도, 바람을 볼 수 있습니다. |
| ✅ **할 일 정리** | 입력창에 할 일을 적고 **+ 추가**를 누르세요. 체크박스를 누르면 완료 처리되고, **전체 / 진행 중 / 완료**로 나누어 볼 수 있습니다. `×` 버튼으로 삭제할 수 있습니다. |
| ⏱️ **집중 타이머** | **집중 25분** 또는 **휴식 5분**을 선택하고 **시작하기**를 누르세요. 일시정지하거나 초기화할 수도 있습니다. |
| 🧮 **계산기** | 숫자와 연산 버튼으로 계산하세요. `C`는 전체 지우기, `⌫`는 한 글자 지우기, `±`는 부호 변경, `%`는 현재 숫자를 100으로 나누기입니다. |

### 이렇게 사용해 보세요

1. 오늘 해야 할 일 한 가지를 추가합니다.
2. 날씨를 확인하고 필요한 준비를 합니다.
3. 집중 타이머를 시작해 25분 동안 작업합니다.
4. 끝낸 일에 체크하고, 잠깐 쉬어갑니다.

## 알아두면 좋아요

- **할 일은 현재 브라우저에 저장됩니다.** 페이지를 닫았다가 다시 열어도 남아 있지만, 다른 기기·다른 브라우저로 자동 동기화되지는 않습니다. 브라우저 데이터를 삭제하거나 시크릿 모드를 사용하면 사라질 수 있습니다.
- **날씨는 인터넷 연결이 필요합니다.** [Open-Meteo](https://open-meteo.com/)에서 현재 날씨를 가져오며, 처음에는 서울을 표시합니다. 위치 정보 권한은 요청하지 않습니다.
- **집중 타이머는 페이지를 열어 둔 동안 동작합니다.** 페이지를 새로고침하거나 닫으면 타이머가 초기화됩니다.
- 앱은 HTML 파일 하나로 만들어졌습니다. 글꼴은 Google Fonts를 사용하며, 연결이 없으면 기본 글꼴로 표시됩니다.

## 직접 파일로 열기

웹 주소 대신 파일로 사용하고 싶다면 이 저장소의 [`index.html`](index.html)을 다운로드하여 브라우저에서 여세요. 별도의 설치나 빌드 과정은 없습니다. 단, 날씨 조회에는 파일로 열었을 때도 인터넷 연결이 필요합니다.
