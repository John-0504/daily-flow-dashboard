# 오늘의 흐름

계산기, 실시간 날씨, 할 일 목록, 집중 타이머를 한 화면에서 사용할 수 있는 단일 HTML 생산성 앱입니다.

## 사용하기

GitHub Pages 주소를 열거나 `index.html`을 브라우저에서 바로 열면 됩니다. 별도의 설치나 빌드가 필요하지 않습니다.

- 날씨: Open-Meteo에서 서울의 현재 날씨를 불러옵니다. 도시 검색으로 지역을 변경할 수 있습니다. 날씨 조회에는 인터넷 연결이 필요합니다.
- 할 일: 브라우저의 로컬 저장소에 보관됩니다. 다른 기기나 브라우저와 동기화되지 않습니다.
- 집중 타이머: 25분 집중 / 5분 휴식 모드를 제공합니다.
- 계산기: 사칙연산, 소수점, 백분율, 부호 변경을 지원합니다.

폰트는 Google Fonts에서 불러오며, 연결되지 않으면 시스템 글꼴로 표시됩니다.
